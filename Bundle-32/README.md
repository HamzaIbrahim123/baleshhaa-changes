## شو تجربة مقدم اللعبة الجديدة؟
الرئيسية ← استكشف لعبة الحروف ← تجربة دور المقدّم

1. أول خلية يختارها النظام عشوائيًا؛ الضغط الأول يفتح سؤالها.
2. الكبسة التالية على الخلية نفسها برتقالي، ثم أخضر، ثم محايد، ثم **برتقالي مجددًا**. **لا يتم فتح السؤال ثانية** بعد رجوع الخلية محايدة.
3. طالما الخلية الحالية محايدة، **كل الحروف الثانية disabled**، حتى تختار البرتقالي أو الأخضر.
4. حين يصبح لونها برتقاليًا أو أخضر، تقدر تختار خلية محايدة **لم يُفتح سؤالها من قبل** وتبدأ سؤالها الوحيد.
5. بعد فتح سؤال جديد، يظهر زر **«تعديل خلية سابقة»**. اضغطه لتغيير لون خلية سبق أن جاوبت عليها (برتقالي → أخضر → محايد → برتقالي). التعديل لا يغلق السؤال الحالي ولا يعيد الأسئلة.
6. «استسلام الفريقين / كشف الإجابة» ما زال موجودًا، وبعده «سؤال جديد لنفس الحرف». **هذا هو الاستثناء المقصود**: سؤال مختلف بعد استسلام الفريقين، وليس إعادة السؤال القديم بسبب النقر أو التصحيح.
7. كشف الفوز، الألوان، تغييرها بين الجولات والنتيجة تعتمد محرك `engine.ts` الحالي.

## شو الخطوة الأكبر الجديدة؟
- في صفحة تجربة المقدّم، اضغط **«فتح شاشة المتسابقين في تبويب جديد»**.
- افتح التبويبين **بنفس متصفح Chrome وعلى نفس رابط الموقع**؛ شاشة المتسابقين هتتحدث تلقائيًا من المقدّم: 25 خلية، ألوان، سؤال حالي، إجابة بعد الكشف، فائز وخاسر.
- شاشة المتسابقين **للمشاهدة فقط** ولا تملك أزرار تصحيح/نقل أدوار.
- تبويب المقدّم يرسل عبر `BroadcastChannel` **publicState فقط**: لا تظهر الإجابة على شاشة العرض قبل استسلام الفريقين وكشفها.
- لو قفلت المقدّم، شاشة العرض تبيّن أن الاتصال التجريبي انقطع.

**مهم جدًا:** المزامنة بين تبويبات **نفس المتصفح والموقع** فقط، وليست غرفة حقيقية ولا تعمل بين جوالات أو أجهزة منفصلة. لا نستخدم Neon أو Backend أو أسئلة محفوظة أو تسجيل الدخول هنا. لا تغيير على سين جيم ولا بيانات المستخدمين.

## Checkpoints
- النقرات 1 سؤال، 2 برتقالي، 3 أخضر، 4 محايد، 5 برتقالي بدون سؤال.
- قفل باقي الحروف عندما الحالية محايدة، وإلغاء القفل بعد تلوينها.
- شاشة المقدّم: تعديل خلية سبق حلها أثناء سؤال آخر، ثم متابعة السؤال كما كان.
- الاستسلام ثم السؤال البديل (بنفس الحرف، سؤال مختلف).
- تبويب المتسابقين: يطابق التلوين، يخفي الإجابة قبل الكشف، ويظهر النتيجة عند الفوز.
- اختبارات real room / Neon ما زالت المرحلة التالية؛ هذا التحديث مقصود للاختبار البصري فقط.
