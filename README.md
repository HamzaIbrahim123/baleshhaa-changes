# Baleshhaa — Figma Make changes

This repository holds only added/modified files relative to the original [`Baleshhaa`](https://github.com/HamzaIbrahim123/Baleshhaa) Figma Make starter, grouped into numbered bundles.

- [`Bundle-01/`](Bundle-01/): first React UI implementation of the approved Figma desktop designs. Each file sits under its original project-relative path (for example, `Bundle-01/src/App.tsx` maps to `src/App.tsx`).
- Every bundle has a `bundle-manifest.json` and an explanatory `README.md`.
- Copy the **contents** of a bundle into the Figma Make project root, not the enclosing bundle folder.
- The original `Baleshhaa` repository remains unchanged. Backend and database integration are not included in UI Bundle-01.
