## شو الجديد المرئي؟
1. الرئيسية → «استكشف لعبة الحروف».
2. **«تجربة اللوحة الآن»**: نفس ستة السيناريوهات السابقة، لكن خلايا سداسية برؤوس واضحة، حدود داخلية واضحة، وإطار حول اللوحة بأعلى/أسفل أخضر ويمين/يسار برتقالي. لم تعد تختار لونًا من 3 أزرار: الضغط المتكرر على نفس الخلية يحركها محايد → برتقالي → أخضر → محايد.
3. **«تجربة دور المقدّم»**: زر جديد بجانب تجربة اللوحة. اكتب اسمَي الفريقين → اختر أفضل من 1/3/5 → ابدأ.
4. النظام يضيء **الحرف الافتتاحي العشوائي**؛ اختره، يظهر سؤال بسيط وإجابة مثال للمقدم فقط. اختر صح فريق 1 أو فريق 2، خطأ/نقل الفرصة، أو استسلام الفريقين وكشف الإجابة ثم إعادة السؤال.
5. بعد فتح الحرف الأول، يمكن اختيار أي حرف محايد. بعد وصل مسار يظهر الفائز والخاسر جنبًا إلى جنب. إذا كانت المباراة «أفضل من 3/5» يمكنك الانتقال لجولة أخرى وتتبدّل ألوان الفريقين.
6. زر «تصحيح لون خلية» يستخدم الترتيب نفسه (برتقالي ← أخضر ← محايد). زر «معاينة شاشة المتسابقين» يعرض السؤال دون الإجابة غير المكشوفة (بواسطة `publicState` الأصلية).

## قواعد اللعبة المستخدمة
- `src/letters/engine.ts` **كما هو**: البرتقالي يصل اليمين باليسار، الأخضر الأعلى بالأسفل. الفوز يعتمد على تلامس الخلايا السداسية، حتى بمسارات متعرجة.
- `startMatch`, `openQuestion`, `awardCell`, `recordWrongAnswer`, `bothSurrender`, `retrySameCell`, `nextRound`, `cycleOwner`, `publicState` تستخدم وظائف المحرك نفسها. الأسئلة **أمثلة مؤقتة** داخل المكون وليست بنك الأسئلة.
